# 古事類苑 OCR モデル対照ビューア

『古事類苑』の画像（国際日本文化研究センター IIIF）の上に、OCR の枠と、山田形式に変換した識別タグを色分けして表示し、2つのモデル（v4 / v5b）の結果を左右に並べて比較するページです。

**ページを開く：** https://oushiei120.github.io/kojiruien-ocr-viewer/

## 収録データ

| 資料 | 頁 | 備考 |
|---|---|---|
| 文学部一 | 1–1432 | 正解なし |
| 文学部二 | 1–1454 | 正解なし |
| 文学部三 | 1–1486 | 正解なし |
| 人部一 | 1–100 | 識別タグ付きテキストを正解として精度を測定（割注F値：v5b 92.7 / v4 88.9）。下に正解のテキストも表示 |

- **v4**：NDLOCR ver.2.1 のレイアウトモデルを、人手で修正した文学部一の100頁で微調整したもの
- **v5b**：v4 に、既存の識別タグ付きテキスト（天部・歳時部）と OCR 結果を自動で対応付けて作った学習データ（1,038頁、人手作業なし）を追加して学習したもの

## 使い方

- **色分け「山田タグ」**：部名・門名・項名・概説・引用書名（V）・編目（N/M）・資料本文（H/X）・参考資料名（W）・割注（`<wari>`）を色で表示します。一つの行枠の中で書名と本文が切り替わる場合は、文字の位置に応じて枠を分割して着色しています。
- **色分け「OCRの種別」**：本文・割注・ルビ・頭注の枠を表示します。太枠は、もう一方のモデルに対応する枠がない箇所です。「差の大きい頁」から差の大きい頁へ移動できます。
- **差分の枠のみ表示**：もう一方のモデルに対応する枠がない箇所だけを表示します（どちらの色分けでも使えます）。
- **画像の下の山田形式テキスト**：その頁の変換結果（山田形式）を左右に並べて表示します。黄色はもう一方のモデルと異なる文字です。人部一では正解（ルビ・返り点は省略）も表示し、黄色は正解と異なる文字を示します。
- 領域にカーソルを合わせると、認識した文字が表示されます。← → キーで頁を移動できます。

## 注意

- 表示しているのは OCR と自動変換の結果で、人手による校正はしていません。
- 画像は日文研の IIIF サーバーから直接読み込んでいます（本リポジトリには含まれません）。読み込みに数秒かかることがあります。
- 枠の座標は NDLOCR が傾き補正した画像上のものです。傾きの大きい頁では、原画像との間に数ピクセルのずれがあります（両モデル共通）。
